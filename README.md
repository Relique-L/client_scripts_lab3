# Доска публикаций

## Файловая структура

```
client_scripts_lab3
├── app.js
├── index.html
├── README.md
└── style.css
```

## Способ запуска приложения

Открыть файл `index.html` браузере

## Реализованные функции

- Размещена кнопка «Загрузить публикации», область для списка публикаций, форма с подписанными полями «Заголовок» и «Текст», кнопка «Создать публикацию» и область сообщений.
- При нажатии кнопки «Загрузить публикации» выполняется запрос с помощью fetch и async/await по адресу https://jsonplaceholder.typicode.com/posts?_limit=5. После проверки response.ok выводятся данные каждой из 5 публикаций.
- При создании публикации проверяется, что заголовок и текст не пустые после удаления пробелов по краям.
- Пока запрос выполняется, показывается сообщение о загрузке или отправке. Сетевые сбои и неуспешные HTTP-ответы обрабатываются с помощью response.ok и try/catch/finally. После показа понятной ошибки снова активируется кнопка для повторной попытки.
- Используется HTML, CSS и обычный JavaScript без фреймворков. Код JavaScript находится в отдельном файле app.js. Страница обновляется без перезагрузки; текст выводится через textContent.

## Результаты проверки

- При нажатии «Загрузить публикации» появляется 5 записей с заголовками и текстом.
- При отправке пустых полей или одних пробелов появится сообщение, запрос не отправляется.
- При отправке корректных заголовка и текста выводится сообщение об успехе и данные публикации появляются на странице.
- При временной замене адреса GET-запроса на https://jsonplaceholder.typicode.com/postz появится сообщение об ошибке, кнопку можно нажать снова. После проверки был восстановлен правильный адрес.
